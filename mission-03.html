STEP 1 OF 5

Meet CSS, the style language

HTML builds the page. CSS decides how it looks: colours, sizes, shapes and spacing. Every CSS instruction is called a rule.

h1 {
  color: hotpink;
}
  • Selector h1: which part of the page to style.
  • Property color: what to change.
  • Value hotpink: how to change it.

Read it as: “For every h1, make the color hotpink.” The curly brackets { } hold the settings, and each setting ends with a semicolon ;.
